# Luisli Gold ($LGOLD) Dashboard

This is the official dashboard for the **Luisli Gold ($LGOLD)** project, built on the Base network.

## 🛠 Tech Stack
- **Framework:** React with Vite
- **Deployment:** Vercel
- **Blockchain:** Base Mainnet

## 🔗 Onchain Integration
We prioritize transparency and onchain identity. The project is linked to:
- **Basename:** [gingi.base.eth](https://base.org/name/gingi)
- **Verified Contract:** Tracking real-time supply and holder data directly from the Base blockchain.

## 🚀 Vision
$LGOLD is committed to building a resilient, high-signal ecosystem within the Base network. By documenting our progress onchain and maintaining a transparent infrastructure, we contribute to the organic growth of the decentralized web.
